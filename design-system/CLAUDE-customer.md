# CLAUDE-customer.md — 고객 화면 기준

고객 화면(랜딩·브랜드·프로모션)를 만들 때의 기준이다. 골격 CSS 는 `fg-customer.css`, 색·타이포 토큰은 `tokens.css` 를 쓴다.

> **업무 시스템 규칙을 참조하지 않는다. 정보 밀도와 타이포 위계가 다르다.**
> **타이포는 업무와 같은 Title/Body/Caption 17종을 쓴다. 고객 전용 Display 계열은 없다.**

## 설계와 디자인의 경계

**설계(structure)는 반드시 지키고, 디자인(expression)은 페이지마다 다르게 한다.**

### 설계 — 반드시 지킨다

- 섹션은 **네 단**으로 이루어진다: **서브 타이틀 → 메인 타이틀 → 본문 문구 → 콘텐츠 영역** 순서. (각각 `.fgc-label` · `.fgc-title` · `.fgc-subcopy` · 콘텐츠)
- 각 단의 **글자 크기·굵기·색, 그리고 단 사이 간격**은 정해진 값을 쓴다.
- **섹션 상하 여백 100**, **섹션 헤드와 콘텐츠 사이 48**.
- **콘텐츠 폭 1280.**
- **클래스 접두어는 `fgc-` 만** 쓴다.

### 디자인 — 페이지마다 다르게 한다

- 콘텐츠 영역에 **무엇을 넣을지**
- 섹션을 **몇 개** 쓸지, **어떤 순서**로 놓을지
- 섹션 배경을 **어떤 밝기로 조합**할지
- **카피와 이미지**

### 콘텐츠 영역 규칙

- 콘텐츠 영역에는 **정해진 컴포넌트가 없다.** 표·폼·이미지·카드·배너, 무엇이든 그 페이지에 맞게 만든다.
- 다만 무엇을 만들든 아래는 지킨다.
  - **색**은 `tokens.css` 의 변수에서만 고른다. **hex 를 직접 쓰지 않는다.**
  - **글자**는 정의된 **타이포 17종**(Title 8 · Body 4 · Caption 5)에서만 고른다. **임의 크기를 쓰지 않는다.**
  - **여백**은 **spacing 스케일**에서만 고른다.

## 키비주얼

- **키비주얼은 사람이 직접 디자인하는 영역이다.** 실제 캠페인 제목은 **사람이 만든 이미지 안에** 들어간다.
- **키비주얼 안에 제목·서브 텍스트를 HTML 로 넣지 않는다.** 대신 **자리 표시(placeholder)** 를 둔다.
- **자리 표시 스타일:** 배경 `Grey-100` · 테두리 `Grey-300` 1px 점선 · 문구 `Grey-500`(옅게). 세 줄의 글자 크기는 각각 다르다(`fg-customer.css` 기준):
  - 1줄 `[ 키비주얼 영역 ]` (`.fgc-hero__ph-title`) = **Title5 16/600**
  - 2줄 안내 문구 (`.fgc-hero__ph-desc`) = **Title6 16/400**
  - 3줄 권장 크기 (`.fgc-hero__ph-size`) = **Body4 12/400**
- **자리 표시 문구(3줄):**
  - `[ 키비주얼 영역 ]`
  - `캠페인 이미지를 만들어 이 자리에 넣어주세요`
  - `권장 크기 1920 × 640`
- **마크업 주석:** `<!-- 키비주얼: 이미지를 만들어 이 블록을 교체하세요. 권장 1920×640 -->`
- 완성 시 이미지로 이 블록 전체를 교체한다.

## 타이포 (위치별 폰트 매핑)

| 위치 | 토큰 |
|---|---|
| 키비주얼 | 자리 표시 안내 문구만(HTML 제목 없음). 실제 제목은 이미지 안에 — 「키비주얼」 절 참조 |
| 서브 타이틀 (`.fgc-label`) | Title5 16/600 |
| 메인 타이틀 (`.fgc-title`) | Title2 32/600 |
| 본문 문구 (`.fgc-subcopy`) | Title6 16/400 |
| 콘텐츠 영역 글자 | Title6 16/400 · Title7 14/600 |

> **정본 굵기는 600·400 두 가지뿐이다. 700 은 정본에 없다.**
> **서브 타이틀은 순수 텍스트로 만든다.** 배경·테두리를 넣어 버튼이나 캡슐처럼 보이게 하지 않는다.

## 타이포 모바일 축소

모바일(폭 768 이하)에서 큰 제목을 한 단계 줄인다. **모바일용 크기를 새로 만들지 않는다. 정의된 17종 이름 안에서 한 단계 내려간다.** 크기는 변수로 참조하므로 원본 Title 값이 바뀌면 따라간다.

| 데스크톱 | 모바일 |
|---|---|
| Title1 40px | Title3 26px |
| Title2 32px | Title4 22px |
| Title3 26px | Title4 22px |
| Title4 22px | Title5 16px |
| Title5 16px 이하 | 그대로 |

브레이크포인트는 `fg-customer.css` 의 기존 `@media (max-width: 768px)` 하나만 쓴다. 새 브레이크포인트를 만들지 않는다.

## 색

| 계열 | 사용 |
|---|---|
| Primary · Grey · System | 업무 시스템과 같다 |
| Secondary | **고객 화면에서만**, 포인트(뱃지·태그·아이콘·그래프·작은 강조)로 **소량**만. 넓은 배경 금지 — 아래 「색 사용 비중」 |

## 색 사용 비중

- **화면의 기본은 Grey Scale 다.** 배경은 `Grey-50` 이나 `Grey-100`, 글자는 `Grey-900` 과 `Grey-600` 을 쓴다.
- **브랜드를 드러내는 색은 Primary-600 과 Primary-200 이다.** 버튼·링크·섹션 라벨·강조 문구·밑줄·아이콘에 `Primary-600` 을 쓰고, 옅은 섹션 배경에는 `Primary-200` 을 쓴다.
- **Secondary 는 포인트다.** 한 화면에 **최대 2색**까지만 쓴다. 쓰는 자리는 뱃지·태그·아이콘·그래프·작은 강조 블록이다.
- **Secondary 를 히어로 배경이나 섹션 전체 배경으로 쓰지 않는다.** 넓은 면에는 `Primary-200`·`Grey-100`·`Grey-900` 을 쓴다.
- **Secondary 없이 Primary 와 Grey 만으로 화면이 완성되는 것이 기본이다.** Secondary 는 더하는 것이지 채우는 것이 아니다.

## 섹션 배경

- **기본은 `Grey-50`(흰색)이다.**
- 리듬을 주려면 **`Grey-100`** 을 섞는다.
- **`Primary-200`** 은 **강조할 한 영역에만** 쓴다.
- **`Grey-900`** 은 **마무리 밴드**에 쓸 수 있다.

## 문장 부호

- **명사나 명사형으로 끝나는 문장에는 마침표를 찍지 않는다.** 예: 집중을 만드는 책상 / 일하는 공간의 기준 / 대표 라인
- **서술형 어미로 끝나는 문장에는 마침표를 찍는다.** 예: 의자의 기준을 만듭니다.
- **물음표와 느낌표는 그대로 쓴다.**
