# design-qa 검사 항목 모음

18번 화면 생성 테스트에서 발견한 규칙들을 모아둔다.
19번 design-qa 스킬을 갱신할 때 이 목록을 옮긴다.
새 문제가 나오면 여기에 한 줄 추가한다.

## 기계가 잡을 수 있는 것

| 항목 | 무엇을 보는가 |
|---|---|
| 외부 주소 참조 | src 나 href 에 http 로 시작하는 값이 있는지. 아이콘과 이미지는 파일 안에 넣어야 한다. 폰트는 예외로, Design.md 에 명시된 Pretendard CDN 링크는 허용한다 |
| 업무 화면 로고 | data-type 이 internal 인 화면에 fg-logo 가 있는지. 있으면 위반 |
| 임의 hex | style 이나 CSS 에 # 으로 시작하는 색이 직접 쓰였는지 |
| 임의 크기 | 정의된 타이포 17종에 없는 font-size 가 있는지 |
| 접두어 섞임 | 한 파일에 fg- 와 fgc- 가 같이 있는지 |
| 필수 속성 | html 태그에 data-brand 와 data-type 이 있는지 |
| 표 셀 줄바꿈 | 표 셀에 줄바꿈 금지가 걸려 있는지 |
| 표 가로 스크롤 | 표를 감싼 영역에 가로 스크롤이 있는지 |
| 표 하단 테두리 | 총합계 행이 있을 때 아래 선이 감싼 테두리와 겹치는지 |
| 표 병합 행 | 표에 여러 열을 합친 행이 있는지. 있으면 표 밖으로 빼야 한다 |
| 고객 화면 섹션 구조 | 쓴 단이 서브 타이틀, 메인 타이틀, 본문, 콘텐츠 순서를 지켰는지. 서브 타이틀과 콘텐츠 영역은 없어도 된다. 순서만 지키면 통과다 |
| Secondary 넓은 면 | 고객 화면에서 Secondary 를 히어로나 섹션 전체 배경에 썼는지 |
| 사이드바 시스템명 | Title5 16px SemiBold 인지 |
| 링크 태그 | fg-link 클래스가 a 태그에 붙어 있는지. span 이면 위반 |
| 페이지네이션 태그 | fg-pagination__nums 안 숫자가 button 태그인지. span 이면 위반 |
| 체크박스 input 태그 | fg-check 안에 input 태그가 있는지. span 만이면 위반 |
| 체크박스 상태 방식 | 상태를 is-checked·is-multiple 클래스로 주고 있는지. 있으면 위반(checked·disabled·indeterminate 로 줘야 한다) |
| 표 전체선택 스크립트 | 표 헤더(thead)에 체크박스가 있는데 전체선택 스크립트가 없으면 위반 |
| 브레이크포인트 신설 | 768 외의 @media 브레이크포인트를 새로 만들었으면 위반 |
