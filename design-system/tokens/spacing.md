# Spacing / Radius — SIDIZ 간격·코너 토큰

원본: Figma `시디즈_디자인 시스템` (`UsCx1wPybDpRRBglYY5Nmx`), `sources/figma-raw.json` 파싱.

## 결론: 이 파일에는 **간격/그리드/radius 정식 토큰이 없다**

published 스타일 카테고리는 **FILL / TEXT / EFFECT 3종뿐**이며, spacing·radius·grid를 위한 스타일이나 변수 카테고리는 노출되지 않는다. 따라서 아래는 *토큰*이 아니라 **컴포넌트 지오메트리에서 관찰된 값**이다.

## 관찰된 코너 radius (컴포넌트 내부)

| 값 | 관찰 빈도 | 비고 |
|---|---|---|
| `2px` | 3 | 소수 컴포넌트 내부 요소 |
| (그 외) | — | 컴포넌트 루트 대부분 radius 미지정 또는 변수 바인딩 추정 `[확인 필요]` |

- 컴포넌트셋 래퍼에서 나온 `5px`(×34)·`20px` 패딩/갭은 **Figma 배리언트 컨테이너 기본값**이라 토큰 아님 → 제외함.
- 각 컴포넌트의 실제 radius/padding/gap은 `[5] components/` 문서에서 **컴포넌트별로** 기록한다.

## 관찰된 패딩 (컴포넌트 내부, 토큰 아님)

`1 / 6.5 / 7 / 7.5 / 9 px` 등 소수만 관찰됨. 일관된 4·8 그리드 스케일로 정리된 토큰은 확인되지 않음.
