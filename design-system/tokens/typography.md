## 사용 규칙

- 국문 `ko/*`·주 스케일, 영문·숫자 `en/*`. 컴포넌트 조밀 텍스트는 컴팩트 UI 스케일.
- **최소 크기 caption2(11px)**. 컴팩트 스케일의 8·10px는 컴포넌트 내부 보조 표기 한정.

## 확인 필요

- `Body 1/Normal - Bold` — 파일 내 미적용, 값 추출 불가.
- 여러 네이밍 세대(주 스케일 / ko·en / 컴팩트 / 레거시) 중 **정본(canonical)** 이 무엇인지 — 통합 대상 확인 필요.
