## 1. Basic — Gray 팔레트 ✅

무채색 기본 팔레트. 배경 · 보더 · 텍스트의 기반이 되는 중립색.

| 토큰 이름 | 값 | 용도 | 사용 규칙 |
|---|---|---|---|
| `basic/gray/000` | `#FFFFFF` | 기본 배경(흰색) | 페이지·카드 기본 배경. |
| `basic/gray/100` | `#F5F6F7` | 옅은 면 배경 | 캔버스/섹션 구분용 옅은 배경. 대면적 채움 OK. |
| `basic/gray/200` | `#EAEDF0` | 옅은 보더 / 구분선 | 헤어라인·구분선. [확인 필요] 보더 전용 매핑 여부. |
| `basic/gray/300` | `#D6DADE` | 보더 / 비활성 라인 | 입력 필드 보더 등. [확인 필요] 정확한 역할. |
| `basic/gray/400` | `#A4AAB0` | disable · placeholder 계열 | 저강조 요소. [확인 필요] 텍스트/보더 구분. |
| `basic/gray/500` | `#7C8084` | 보조 텍스트 계열 | [확인 필요] `text_*` 시맨틱과의 매핑. |
| `basic/gray/600` | `#595C5E` | 보조/본문 텍스트 계열 | [확인 필요] 시맨틱 매핑. |
| `basic/gray/700` | `#434548` | 본문 텍스트 계열 | [확인 필요] 시맨틱 매핑. |
| `basic/gray/800` | `#242526` | 주 텍스트 / 진한 면 | [확인 필요] 시맨틱 매핑. |
| `basic/gray/900` | `[확인 필요]` | 최고 강도 무채색(추정) | 이번 조회 결과에 미포함. [확인 필요] 존재 여부·값. |

> **주의:** gray 각 단계의 "용도"는 일반 관례에 따른 초안이며, gray 단계 ↔ 시맨틱 역할의 **정확한 매핑은 `[확인 필요]`** 다. 아래 시맨틱 컬러 값을 읽어 확정한다.

## 3. Semantic — Text 컬러 [확인 필요]

텍스트 전용 시맨틱 컬러. 이름·용도는 Figma에서 확인됨. **HEX 값은 미확보(`[확인 필요]`).**
`_d` 접미사는 진한(dark) 배경 위에서 쓰는 대응 컬러.

| 토큰 이름 | 값 | 용도 | 사용 규칙 |
|---|---|---|---|
| `text_primary` | `[확인 필요]` | 명확히 전달돼야 하는 텍스트. Header·주요 body | 제목·핵심 본문에 사용. |
| `text_primary_d` | `[확인 필요]` | 진한 배경 위 primary 텍스트 | 다크 배경 위에서만. |
| `text_secondary` | `[확인 필요]` | 덜 선명한 텍스트. 양 많은 body·Input label | 보조 본문·라벨. |
| `text_secondary_d` | `[확인 필요]` | 진한 배경 위 secondary 텍스트 | 다크 배경 위에서만. |
| `text_tertiary` | `[확인 필요]` | 보조/저강조 텍스트 | 3차 위계 텍스트. |
| `text_tertiary_d` | `[확인 필요]` | 진한 배경 위 tertiary 텍스트 | 다크 배경 위에서만. |
| `text_disable-placeholder` | `[확인 필요]` | placeholder · disable 상태 텍스트 | 비활성/입력 전 안내에만. |
| `text_select` | `[확인 필요]` | 선택 상태 텍스트 | 선택/활성 텍스트 강조. |
| `text_select_d` | `[확인 필요]` | 진한 배경 위 select 텍스트 | 다크 배경 위에서만. |
| `text_error` | `[확인 필요]` | 에러 안내·중요 정보 텍스트 | 에러/중요 안내에만. |
